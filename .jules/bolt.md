## 2024-05-18 - Isolate modal state to prevent full-page re-renders
**Learning:** In a multi-page React application with complex nested components (like `App.tsx` handling routes, headers, footers), defining global modal states at the root level causes the entire application tree to re-render whenever a modal opens or closes. This is a significant performance bottleneck, especially if child components are not heavily memoized.
**Action:** Always isolate global UI states (like modals, toasts, or overlays) into their own specific wrapper components (e.g., `<Modals />`) and place them alongside the main application structure. Use `React.memo` on these wrappers to ensure their state changes don't unnecessarily cascade, or simply ensure the state is contained within the wrapper so only the wrapper re-renders.
