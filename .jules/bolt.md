## 2024-05-18 - Extracting Modal State to Prevent Top-level Re-renders
**Learning:** React with React Router handles `window.addEventListener('message')` at the top level by re-rendering the entire routing tree (including Header and Footer) whenever state updates are triggered from deeply nested child components via `postMessage`. This results in expensive, unnecessary DOM diffing for static layout elements.
**Action:** When global overlay UI (like Modals) needs to be triggered from anywhere in the app via events, encapsulate their state and the event listener into an isolated, `React.memo()` wrapped component placed inside the Router but alongside the Routes, preserving the integrity of the rest of the application tree.
