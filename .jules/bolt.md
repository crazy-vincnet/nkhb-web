## 2024-10-24 - Prevent Full-Page Re-renders from Modal State
**Learning:** In the React setup for `src/public`, the global state logic for three distinct modals was originally housed at the root level in `App.tsx`. Because `window.postMessage` events triggering `setState` lived in the top-level `<App>` component, whenever any modal was opened or closed, it forced a full re-render of all routes and sub-components (like `Home`, `Header`, `Footer`).
**Action:** Isolate non-route-blocking top-level states (like modals) into a separate, dedicated container component (e.g., `<Modals />`). Apply `React.memo` to this wrapper component so its internal state changes (modal toggles) do not trigger unnecessary cascading re-renders down the main React DOM tree, drastically improving rendering performance when interacting with modal popups.
