## 2024-10-27 - [Isolate modal state to prevent full-page re-renders]
**Learning:** In React applications where modal state (e.g., `isModalOpen`) is managed at the root component level (like `App.tsx`), toggling modals triggers a re-render of the entire component tree, even if child components are memoized. This can lead to significant performance bottlenecks, especially in larger applications.
**Action:** When implementing modal management or similar global overlay states, isolate the state variables and event listeners into a dedicated wrapper component (e.g., `<Modals />`). Place this wrapper *inside* the router context (so it has access to router hooks if needed), and wrap it in `React.memo()`. This ensures only the modal wrapper re-renders when a modal is toggled, preventing cascading re-renders across the rest of the application.
