## 2024-05-24 - Isolate Modal State to Prevent Top-Level Re-renders
**Learning:** In a multi-page Vite setup (or similar SPA architecture), keeping modal visibility state (like `isArticleModalOpen`) at the very top level (`App.tsx`) causes the entire application tree, including complex nested routes, to re-render every time a modal is opened or closed. This is particularly problematic in this codebase where modals are triggered via `window.postMessage` events from deeply nested child components.
**Action:** Extract such isolated UI state into a separate component (e.g., `<Modals />`) wrapped in `React.memo` and place it alongside (or inside) the main router context. This ensures that only the modals re-render on state changes, significantly improving perceived performance when interacting with modal triggers.
