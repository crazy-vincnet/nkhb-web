## 2024-07-23 - Prevent Full-Page Re-renders from Modal State
**Learning:** In the React application, keeping modal visibility state (e.g., `isArticleModalOpen`) in the root `App.tsx` component causes the entire component tree (including `<Header>`, `<Routes>`, and all page content) to re-render whenever a modal is opened or closed. This is especially problematic if child components are not heavily memoized.
**Action:** Isolate global modal states into a separate `<Modals />` component and wrap it in `React.memo`. Place this component adjacent to the main app container in the root layout. This ensures that state updates from `window.postMessage` events only trigger re-renders within the isolated `<Modals />` component, preventing unnecessary full-page updates and improving overall performance.
