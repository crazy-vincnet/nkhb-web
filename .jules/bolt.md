## 2025-02-23 - Isolate React modal state to prevent router re-renders
**Learning:** In this Vite/React 18 architecture using `react-router-dom` and a `window.postMessage` bridge for triggering modals, placing the modal state variables and event listener at the root `<App />` component level caused unnecessary full-tree re-renders (including the Router and all child layout elements) whenever a modal opened or closed.
**Action:** Extract deeply nested event listeners and their associated state into dedicated wrapper components (like `<Modals />`). Place these wrappers *inside* the `<Router>` (if they depend on router context) but out of the direct render path of the core layout. Always wrap these isolated state components in `React.memo()` to ensure they act as an optimization barrier.
