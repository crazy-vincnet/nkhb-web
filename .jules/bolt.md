## 2024-10-24 - Isolated Modal State Prevents Full-Page Re-renders
**Learning:** In the Vite/React architecture for this static/dynamic hybrid app, keeping modal state (`isArticleModalOpen`, etc.) and the global `message` event listener in the root `App.tsx` caused the entire application (including `<Header>`, `<Routes>`, `<Footer>`) to re-render whenever a modal was toggled via `window.postMessage`. This was a significant performance bottleneck when interacting with deep child components.
**Action:** Always colocate state as close to where it is needed as possible. By extracting the modal state and the `window.postMessage` listener into an isolated `<Modals />` wrapper component and applying `React.memo`, we ensure that triggering a modal only re-renders the modals themselves, not the entire React router tree.
